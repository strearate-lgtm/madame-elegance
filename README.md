# Madame Élégance – Site remanié

Version moderne du site de Sorelle M / Madame Élégance.

## Contenu récupéré (hors boutique)
- Accueil avec présentation
- Qui suis-je (bio complète)
- Mon Book (galerie d'œuvres)
- Expositions
- Contact
- Politique de confidentialité
- Liens réseaux sociaux

## Design
- Design contemporain, élégant, minimaliste
- Typographies : Playfair Display + Inter
- Palette : Noir profond, or, crème
- Responsive (mobile + desktop)
- Galerie avec lightbox
- Navigation fixe

## Utilisation
Ouvrez simplement `index.html` dans un navigateur.

Les images pointent vers le site actuel (URLs originales). Pour une version autonome, téléchargez les images et mettez à jour les chemins.
